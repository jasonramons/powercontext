把错题变成
今天该复习的清单

错题本不怕记，怕的是记完再也没打开过。Study Buddy 让每道错题带着知识点、掌握度和到期时间回到你面前。

  • 不知道今天该复习什么 —— 按掌握度和到期时间排出当日清单，打开就知道做哪几题。
  • 找不到相似的旧题 —— 粘贴新题或输入关键词，相似旧错题按匹配度排序返回。
  • 反复错的知识点没人提醒 —— 连续答错的知识点被写入记忆，下次主动浮现。

        02 / Features

        三件事，覆盖错题复习的一整轮闭环

        今日复习计划

        不再凭感觉翻错题本。每道错题都带掌握度与到期时间，系统按「先逾期、再低掌握度」排出当天真正该做的几题。

        谁在算
        • 到期时间由答对 / 答错动态顺延或提前
        • 掌握度随每次作答实时变化
        • 清单数量受控，避免一次堆几十题

        相似题检索

        遇到新题先问一句「以前错错过类似的吗」。seekdb 在一个嵌入式库里同时跑 HNSW 向量近邻与关键词检索，命中的旧错题带回知识点标签与当时的掌握度。

        谁在算
        • seekdb 混合检索：语义相似 + 关键词精确
        • 嵌入式部署，无需单独拉起数据库服务
        • 结果按匹配度排序，最相似的排第一

        薄弱点记忆

        同一知识点反复答错，说明缺的不是这道题，而是它背后的概念。PowerContext 把学习者的薄弱点持久化下来，并在后续复习与检索时主动提醒。

        谁在算
        • 答错时把该题知识点写入 PowerContext
        • 累计答错 ≥ 2 次的知识点标记为薄弱点
        • 下次进入复习或检索时自动召回并置顶

        03 / Architecture

        技术架构：从开发工具到学习者记忆

        四段链路，各自负责一件事。数据库负责找得准，记忆层负责记得住，Node 服务负责把它们交给浏览器。

        • 需求拆解与全栈代码生成

        02

        seekdb

        嵌入式向量数据库

        错题题干与知识点向量存在同一个库里，HNSW 近邻检索负责「意思像」，关键词检索负责「字面准」，两路结果合并排序。

        • HNSW 向量索引 + 关键词混合检索
        • 嵌入式运行，轻量易起

        03

        PowerContext

        学习者记忆

        把「谁在哪些知识点上反复出错」当作长期上下文保存下来。答错即写入，复习与检索时召回，让提醒有依据而不是靠规则硬编码。

        • 薄弱知识点写入与召回
        • 掌握度、错误次数等学习状态持久化
        记忆写入上下文召回

        • 复习清单 / 相似题检索接口
